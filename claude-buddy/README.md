# Claude Buddy — живой 3D-Клод на твоём мониторе

Маленький коралловый колобок с короной-искоркой сидит на грибе-табуретке на полупрозрачном летающем островке в углу экрана, поверх всех окон. С ним можно говорить голосом или текстом. У него есть эмоции, рот двигается в такт речи, глаза следят за курсором. По просьбе он поворачивается к экрану и комментирует, что там видит.

- **Появление:** спускается сверху на ниточке, пищит «Ку-ку! Ты где?», нитка рвётся, **БАМ!**, и он уже сидит на грибе.
- **Прятки:** просишь уйти (голосом, хоткеем, через меню), он улетает вверх по нитке, островок схлопывается. Пока он спрятан, иногда спускается подглядывать: «ку-ку… ты где?». Кликнешь по нему, он спрыгнет обратно. Не кликнешь, обидится и уползёт.
- **13 эмоций:** neutral, happy, laugh (глаза ^^), surprised, sad, angry, thinking (чешет репу), love (сердечки в глазах), smug, sleepy, scared, embarrassed (румянец), wink. Claude сам ставит их тегами по ходу ответа.
- **Взгляд на монитор:** Claude сам решает, когда взглянуть (инструмент `look_at_screen`), или ты жмёшь 👁 / `Ctrl+Alt+L`. Скриншот делается **только** в этот момент, и персонаж показывает это: поворачивается к экрану, щурится, «щёлк».
- **Жизнь:** дышит, моргает, болтает ножками, следит глазами за мышкой по всему экрану, засыпает от скуки (Zzz), обижается на тычки («Эй, я тебе не кнопка!»).
- **Мелочи в простое:** следит глазами за летающим кристалликом, косится на кружку с кофе (над ней идёт пар) и на деревце, переминается, мурлычет себе под нос.
- **Звуки:** мультяшные, синтезируются на лету, без файлов: «боинг» на приземлении, писк на тычок, «вжух» джетпака, щелчок оборванной нитки, нотки в танце. Выключаются вместе с «Без звука».
- **Трюки:** джетпак (летает петлями, крутится волчком, дымит), сальто, танец с нотками, потягушки. Скажи «полетай» или «станцуй», и Claude сам вставит тег `[jetpack]` / `[dance]` / `[backflip]`. Трюк выполняется сразу, без лишнего запроса к API.
- **Самодеятельность:** если ты долго молчишь, он иногда сам что-нибудь выкидывает: полетает, станцует, скажет «эй, ты там живой?». Отключается в настройках.
- **Самосовершенствование:** долгая память между запусками. Он сам запоминает факты о тебе и **уроки себе**: скажешь «длинно говоришь» или «меньше мата», и он запишет правило и будет ему следовать. Вслух скажет «урок усвоен». Память хранится только у тебя. В настройках видно каждую запись: её можно удалить по одной или стереть всё. Ещё можно попросить вслух («забудь, что…»). Секреты (ключи, пароли, номера карт) он не запоминает. Уроки себе в ходе со скриншотом не записывает, чтобы текст на экране не мог «перепрошить» ему характер.
- **Помнит контекст между репликами:** знает время суток, сколько тебя не было, что сам говорил от скуки, сколько раз его тыкали и сколько он проспал.
- **Спит, только когда тебя нет:** пока двигается мышь, он не засыпает. Вернулся — проснётся, потянется и скажет «я не спал, я медитировал». Во сне бормочет.
- **Клик сквозь:** всё вокруг персонажа прозрачно для мыши, работать он не мешает. Островок можно таскать мышкой по краю экрана и на другой монитор.

## Запуск (Windows)

1. Поставь [Node.js LTS](https://nodejs.org).
2. Дважды кликни `start-windows.bat`. Первый раз он поставит зависимости.
3. Откроются настройки: вставь **API-ключ Anthropic** ([console.anthropic.com](https://console.anthropic.com)), нажми «Сохранить».

Или из консоли:

```sh
cd claude-buddy
npm install
npm start
```

Собрать один portable `.exe`: `npm run dist` (появится в `dist/`).

## Управление

| Что | Как |
| --- | --- |
| Поговорить (откроет поле, а если настроено распознавание, сразу слушает) | `Ctrl+Alt+K`, клик по островку или по персонажу |
| Спрятать / позвать | `Ctrl+Alt+H`, клик по иконке в трее |
| Посмотри на мой экран | `Ctrl+Alt+L`, кнопка 👁 в поле чата |
| Меню (без звука, забыть разговор, настройки, выход) | правый клик по персонажу/островку, иконка в трее |
| Перетащить | зажми островок и тащи |

Хоткеи меняются в настройках.

## Голос

- **Говорит** системным синтезатором. В Windows есть русские голоса (Irina, Pavel). Если голоса нет: Параметры → Время и язык → Речь → Добавить голоса. Высота и скорость настраиваются, по умолчанию голос чуть мультяшный. «Ку-ку» он пищит отдельным микро-голоском.
- **Слышит** через любой OpenAI-совместимый `/audio/transcriptions`: OpenAI `whisper-1`, Groq (`https://api.groq.com/openai/v1` + `whisper-large-v3-turbo`, быстро и дёшево) или свой локальный whisper-сервер. Запись останавливается сама, когда ты замолчал.
- Без отдельного распознавания тоже можно: открой поле чата и нажми **Win+H**, тогда Windows сама надиктует текст.

## Мозги и деньги

- По умолчанию модель `claude-opus-5-5` с `effort: low`, для живой болтовни этого хватает. В настройках можно выбрать Sonnet 5.5 или Haiku 5.5, они быстрее и дешевле.
- Стриминг: озвучка начинается с первого готового предложения, весь ответ ждать не надо.
- Системный промпт кэшируется, история разговора только дописывается (append-only). Так кэш работает лучше и не ломаются thinking-блоки.
- Включён серверный fallback на случай отказа модели (`fallbacks: "default"`). Если аккаунт или платформа не поддерживает бета-поля, бадди сам переключится на простой запрос.
- Кэшируется и системный промпт, и вся история разговора. Старые реплики и скриншоты при каждом новом вопросе стоят примерно десятую часть цены.
- Скриншот уходит в API только когда персонаж «смотрит» (один JPEG ≈ 1.5–2 тыс. токенов). Отключается галкой в настройках.

## Приватность

- Ключи хранятся локально и шифруются системным хранилищем (DPAPI на Windows), в окно с персонажем они не попадают.
- Экран не снимается в фоне, только по просьбе, и каждый раз это видно по анимации.
- Микрофон пишет только когда ты нажал «говорить».

## Превью без ключа

```sh
npm run preview   # http://localhost:5178/
```

Откроется в обычном браузере с заглушкой вместо Claude: видно анимации, эмоции и спуск на нитке (`window.__buddy.scene.setEmotion('love')` в консоли).

## Как устроено

```
src/main/main.js      прозрачное окно поверх всех, клик-сквозь, трей, хоткеи, скриншоты, перетаскивание
src/main/brain.js     разговор с Claude: Anthropic SDK, стриминг, инструменты look_at_screen / hide_myself
src/main/stt.js       распознавание речи (OpenAI-совместимый API)
src/main/memory.js    долгая память: факты о пользователе и уроки себе
src/main/config.js    настройки + шифрование ключей
src/preload.js        узкий мост main ↔ окно
src/renderer/scene.js three.js: островок, гриб, колобок, мимика, нитка, частицы
src/renderer/voice.js озвучка, липсинк по словам, микрофон с автоостановкой
src/renderer/sfx.js   мультяшные звуки на WebAudio
src/renderer/app.js   режиссёр: появление, прятки, сон, тычки, облачко, чат
```

Персонаж и островок целиком процедурные, внешних 3D-моделей нет.
