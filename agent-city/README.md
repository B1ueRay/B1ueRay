# Город агентов B1ueRay

3D-город, где каждое здание — команда ИИ-агентов, и агенты работают по-настоящему. Задача уходит в Штаб, тот пишет ТЗ командам, команды сдают готовый результат, Перепроверка ищет косяки и при необходимости возвращает работу на доработку, AI-аналитика ставит обоснованную оценку, а отчёт ложится в Дом босса.

Один файл `index.html`, без сборки и бэкенда. Three.js r160, marked и DOMPurify грузятся с jsDelivr.

## Где работают агенты

Агенты обращаются к Claude через возможности артефакта claude.ai: `sample` для запросов к Claude, `db` для хранения результатов, `downloads` для скачивания файлов. Поэтому реальная работа идёт, только когда страница открыта как артефакт в claude.ai:

- Каждая задача тратит лимиты твоего аккаунта Claude. Это 4–7 запросов: штаб, по одному на каждую команду, QA, при доработке ещё по одному на команду, аналитика.
- При первом запуске claude.ai спросит разрешение пустить страницу к Claude.
- Если открыть `index.html` просто в браузере, город показывается, но агенты стоят, и об этом написано на странице.

## Где смотреть результаты

- **Лента задач слева.** Там статус каждой задачи и кнопка «Открыть результат». Пока задача в работе, кнопка называется «Смотреть, что пишут», и текст виден прямо в процессе.
- **Дом босса.** Во «Входящих» лежат все задачи с оценками.
- **Здание команды.** Внутри на стене монитора видно, что агенты печатают прямо сейчас. Справа список «Работы команды».
- **Окно отчёта.** Разделы: Итог, План штаба, работа каждой команды (`v2`, если её доработали после QA), Перепроверка, AI-аналитика. Любой раздел можно скопировать или скачать. «Скачать всё» сохраняет весь отчёт одним `.md`.

Результаты хранятся в базе артефакта, их видно после перезагрузки и с других устройств. Задача, которую оборвали закрытием страницы, через 20 минут помечается как прерванная.

## Здания

| Здание | Что делает |
| --- | --- |
| Штаб «Луч» | выбирает от 1 до 3 нужных команд и пишет каждой ТЗ |
| Разработка | пишет код, файлы идут блоками; рядом стоят VELORA и БухМет |
| Дизайн | делает спеку: палитра, шрифты, раскладка, компоненты, тексты |
| Маркетинг | пишет сценарий рилса, посты, сторис и рекламный текст |
| Перепроверка | ищет реальные проблемы и один раз возвращает работу на доработку |
| AI-аналитика | ставит оценку из 10, называет сильные стороны, риски и следующие шаги |
| Отправка | упаковывает отчёт и отправляет в Дом босса |
| Дом босса | это ты: все результаты, за каждую готовую задачу на башне появляется кольцо |

Одновременно в работе может быть до двух задач. Любую можно остановить кнопкой «Стоп».

## Управление

- Мышь: тяни, чтобы лететь над городом. Правая кнопка или Shift+перетаскивание поворачивают и наклоняют камеру. Колесо приближает к курсору.
- Клавиатура: WASD или стрелки летают (с Shift быстрее), Q/E поворачивают, R/F приближают и отдаляют. Работает и на русской раскладке.
- Телефон: один палец двигает, двумя щипком приближаешь, сдвигом двух пальцев наклоняешь и поворачиваешь.
- Двойной клик или двойной тап по земле плавно переносит туда камеру. Любое касание прерывает анимацию перелёта. Кнопка «?» показывает подсказку.
- Клик по зданию или его подписи: камера залетает внутрь, а справа открывается карточка команды. `Esc` или «×» возвращают к обзору.
- Кнопки сверху: «Управление», «Обзор», «День/Ночь», «Свечение» (выключи на слабом телефоне).

## Локальный запуск

```sh
cd agent-city
python3 -m http.server 8080
# потом открой localhost:8080
```

Локально агенты не работают, только город: доступ к Claude даёт claude.ai.
