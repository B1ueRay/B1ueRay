# Город агентов B1ueRay

Живой 3D-город, где каждое здание — команда ИИ-агентов. Задача падает в Штаб, разлетается по командам, проходит перепроверку, получает оценку AI-аналитики и улетает боссу.

Один файл `index.html`, без сборки и бэкенда. Three.js r160 грузится с jsDelivr.

## Запуск

Открой `index.html` в браузере. Если браузер ругается на модули с `file://`, подними любой статический сервер:

```sh
cd agent-city
python3 -m http.server 8080
# потом открой localhost:8080
```

## Что внутри

| Здание | Роль |
| --- | --- |
| Штаб «Луч» | оркестратор: разбирает задачу и раздаёт командам |
| Разработка | код; рядом стоят VELORA и БухМет |
| Дизайн | интерфейсы, бренд, анимации |
| Маркетинг | рилсы, посты, реклама; на крыше крутится билборд |
| Перепроверка | QA; в 35% случаев возвращает задачу на доработку |
| AI-аналитика | ставит оценку из 10 |
| Отправка | упаковывает результат и шлёт боссу |

## Управление

- Перетаскивай, чтобы крутить город. Колесо или щипок меняют масштаб.
- Клик по зданию или его подписи: камера залетает внутрь, здание становится прозрачным, справа открываются агенты и живой лог. `Esc` или «×» возвращают к обзору.
- Внизу можно вписать свою задачу. Команды подбираются по ключевым словам: «сайт», «баг» и «бот» уходят в Разработку, «лого» и «макет» в Дизайн, «рилс» и «пост» в Маркетинг.
- Кнопки сверху: «Обзор», «Скорость» ×1/×2/×4, «Автопилот» (демо-задачи сами по себе), «День/Ночь», «Свечение» (выключи на слабом телефоне).

Работа агентов здесь симулируется: реальные модели не вызываются, реплики и оценки генерируются на месте.
