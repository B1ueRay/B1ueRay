# AI Squat Coach

Прототип ИИ-коуча по технике: смотрит на тебя через камеру телефона/ноутбука прямо в браузере и голосом подсказывает, что поправить — глубину присеста, наклон спины, темп движения. Видео никуда не отправляется — вся обработка (распознавание позы) идёт локально в браузере.

## Как это работает

- Веб-камера → [MediaPipe Pose Landmarker](https://developers.google.com/mediapipe) (в браузере, через CDN) находит точки тела 30 раз в секунду.
- По точкам плеча/бедра/колена/лодыжки считаются углы (угол в колене, наклон корпуса) и строится конечный автомат фаз приседа: стойка → опускание → низ → подъём.
- По завершении повторения или в реальном времени при опасном наклоне спины выбирается одна подсказка и озвучивается через Web Speech API (`speechSynthesis`), плюс показывается текстом на экране.
- Поддержаны 3 языка интерфейса и голоса: укр/рус/англ.

Это MVP на одно упражнение (приседания) с жёстко заданными биомеханическими порогами, а не универсальная модель «на любое упражнение» — для надёжных подсказок на силовых каждое упражнение нужно описывать отдельно.

## Запуск

```bash
cd ai-squat-coach
npm install
npm start
```

Открыть `http://localhost:3300` (или по сети — см. ниже) с телефона/ноутбука, у которого есть камера. Нужен HTTPS или `localhost` — иначе браузер не даст доступ к камере.

## Советы для теста

- Поставь телефон так, чтобы в кадре было видно тебя в полный рост, желательно немного сбоку — так точнее считается наклон спины.
- Включи звук или наушники — подсказки озвучиваются.
- Внизу экрана есть строка `knee / torso` — сырые углы в градусах, полезно для отладки.
